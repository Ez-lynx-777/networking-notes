# DNS (Domain Name System)

## What is DNS?

DNS translates human-readable domain names into IP addresses.

Example:

google.com

↓

142.250.xxx.xxx

## Why is DNS important?

- Makes websites easy to access
- Eliminates the need to remember IP addresses
- Used in every web request

## Real-world example

When you visit youtube.com:

1. Your browser asks the DNS server.
2. The DNS server returns YouTube's IP address.
3. Your browser connects to that IP.

## Commands

nslookup google.com
