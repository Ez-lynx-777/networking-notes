# HTTP and HTTPS

## What I Learned

- HTTP stands for Hypertext Transfer Protocol.
- HTTPS stands for Hypertext Transfer Protocol Secure.
- HTTP is used for communication between a browser and a web server.
- HTTP commonly uses TCP port 80.
- HTTPS uses TLS to protect communication between the browser and server.
- HTTPS commonly uses TCP port 443.
- HTTPS provides encryption, integrity, and authentication.
- HTTP uses requests and responses to communicate with web servers.
- Common HTTP methods include GET and POST.
- Common HTTP status codes include 200, 404, and 500.

HTTP and HTTPS are protocols used for communication between a **web browser (client)** and a **web server**.
