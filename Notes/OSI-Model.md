# OSI Model

## What is the OSI Model?

The OSI (Open Systems Interconnection) Model is a conceptual framework that explains how data travels from one computer to another through seven layers.

## Layers

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application

## Why is it important?

- Helps understand networking
- Makes troubleshooting easier
- Used in networking and cybersecurity
